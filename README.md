Solmaris Heat is an original open-world crime game that runs entirely in the browser. You play Mara Voss, a driver and fixer-for-hire in the sun-baked port city of Solmaris, taking jobs from the fixer Dario Quint and crossing paths with the Ledger crew who run the docks. Explore the city on foot or behind the wheel, weave through live traffic and pedestrians, build up a wanted level and shake the police, and work through a 6-mission story of pickups, chases and shootouts — with a full HUD, minimap, and save support so you can pick up where you left off.

## Run it

```sh
node serve.ts
```

Then open `game/index.html` in your browser (any static file server works too).

## Controls

- **WASD** — move / drive
- **E** — steal or enter a car
- **Mouse** — aim
- **M** — map
